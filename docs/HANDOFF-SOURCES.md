# 本机会话来源识别与接续

## 当前桌面读取路径

桌面端统一使用持久化元数据索引，按来源、项目、会话类别分页，搜索覆盖尚未加载的分页。筛选使用当前索引；点击“刷新”才重新扫描来源，列表显示索引时间。切换来源会保留各自的筛选和浏览位置；来源版本改变后重新加载，不复用失效分页。

安装身份与历史可读性分别判断，不把残留配置目录视为已安装程序。只有安装记录、没有验证过聊天结构的工具不会冒充可读取来源。项目和会话记录不代表任务已完成，也不证明工具正在使用某个账号或模型。

| 来源 | 索引和读取范围 |
| --- | --- |
| OpenCode | 原生项目登记、新旧会话存储和原生导出 JSON |
| Codex | 项目登记、状态库、普通及压缩历史，包括独立和归档记录 |
| Claude Code | 本地项目、会话及子会话历史 |
| WorkBuddy | 原生会话索引和项目中的历史记录 |
| ZCode | CLI 存储与客户端项目、会话登记，保留不同原生 ID 格式 |
| WisCode | 原生宿主记录及独立的 Claude / Codex 引擎历史 |
| DeepSeek Harness | 本地持久化的会话缓存和压缩日志 |
| 极库 Copilot Code | 原生任务索引、独立宿主与扩展保存的会话；项目关联可能仍待确认 |
| VS Code / Copilot | 工作区和扩展保存的历史，缺少正文的索引条目保留缺口 |
| Cursor | 原生索引与消息存储，保留空项目和记录关联 |

Gemini CLI 缺少本机真实样本；Windsurf、Trae 尚无经过验证的原生历史适配。不能宣称所有工具或所有版本完整覆盖。实际数量、来源差异与缺口见[上下文验收记录](validation/任务接续识别与上下文验收.md)。远端或自定义 profile 需要显式选择实际的数据目录，不自动取得未保存或已删除的内容。

## 从会话到接续内容

1. 选择会话后只读取得历史。来源摘要分别显示“对话消息”和“原始事件”，不把两种数量混为一谈。
2. 配置页先展示目标 AI、继续目标和任务范围；历史核对与完整原始上下文导出按需展开。
3. “项目 / 文件任务”保留停止并行修改、核对目标工作区的确认。“仅继续对话”会在交接说明中明确不授权工作区文件或命令操作，并要求相应确认；它不能替代目标工具自己的权限控制。
4. 选择会话历史、来源工作区及可选附件，生成实际复制内容的预览。长预览按片段展示，复制仍包含全部文字，不因预览分页截断。预览过期时保留配置，需重新生成后确认。
5. 用户检查全文与已知敏感信息后复制，自行到目标工具粘贴、发送。本应用不自动启动目标任务，也不承诺目标模型能容纳任意长度的上下文。

已提取的可见用户请求和 AI 回复保持原文及顺序；内部思考、工具过程、系统事件等不作为对话正文复制。完整原始归档保留这些来源事件，未经脱敏，只能经过确认后导出到本机。已知格式的敏感信息脱敏仍需人工核对，不能视为完整的秘密识别。

## 附件与原始上下文

全量历史归档中的可取得附件接入现有附件选择和打包流程，也可手动补充当前文件。默认不打包附件；文件路径或远程 URL 不会冒充历史原件，也不自动联网下载。缺失、格式未支持、读取失败和扫描不完整分别显示，未知不等于没有附件。

可选附件包沿用每条 16 MB、合计 64 MB、最多 128 条的扫描边界；超限和未携带内容明确保留说明。完整原始上下文导出仍是独立路径，不受旧兼容读取器的 8 MB、5000 条消息或 120000 字符总量限制，也不因可选附件包的限制而截断归档。

附件原内容未经脱敏。用户确认后先导出 ZIP，再复制说明与实际包路径；导出成功不代表已经复制或上传。用户需要在目标工具中主动选择附件，或在授权范围内解压和读取；仅粘贴文字不会传递附件原件。

## 索引与核验状态

正文、附件、项目及会话覆盖分别呈现。相同来源版本的刷新保留核验状态和时间；原生记录或其存储文件变化后，先前状态失效，需要重新核验。全量核验提供进度与取消，取消返回已完成部分，不把主动取消显示为来源读取失败。

来源数据库使用只读连接，不执行历史命令，不迁移或修复来源数据库。缓存和导出保存在助手自己的位置。当前实机验收以 macOS 为主，其他系统及客户机器仍需独立验证。

## 验证入口

```sh
npm run build
ELECTRON_RUN_AS_NODE=1 node_modules/electron/dist/Electron.app/Contents/MacOS/Electron --import tsx --test tests/*.test.ts
node scripts/verify-history-ui.mjs
node scripts/verify-ux-reliability.mjs
```

两项界面验收使用隔离 HOME、临时数据和示例文件，禁用外部网络，不写系统剪贴板。源码构建、单元回归、桌面交互和正式安装包交付是不同的验收范围。

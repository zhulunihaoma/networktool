# 记忆工作台

入口：左侧「记忆工作台」。顶部以 Codex、Claude Code、Gemini CLI、Cursor、OpenCode 标签切换来源。默认跨文件阅读，左侧文件目录始终保留文件名与出处。

## 浏览内容

- 左侧把总览、入口文件与主题内容分开展示，显示真实相对路径、内容数量与当前出处。点击文件可聚焦其中内容，点击「全部记忆」返回跨文件浏览。
- 「内容总览」按原文章节归类，把不同文件的内容放在一起阅读；常见英文章节名提供中文标签。总览或入口中独有的正文仍然保留。条数按段落统计，不宣称已对事实去重。
- 每张内容卡片保留来源文件和原文行号。主题先展示两项，按需展开；主题很多时可继续加载。
- 右侧并列保留阅读整理与原文。阅读整理只清理格式标记、翻译常见字段名，保留代码、标识和原文内容，不调用模型补写解释。适用场景与示例仅在原文明确提供时显示。
- 点击右侧来源按钮可展开并定位左侧对应文件，不改变当前内容范围。点击文件本身可查看用途与经过脱敏的完整原文。
- 「关系地图」展示跨文件主题与内容，分类节点可打开完整主题内容。实线表示按原文章节归类，虚线仅表示已扫描文档之间的显式 Markdown 引用；不调用模型推断关系。原文引用可在右侧双向跳转。
- 所有内容作为纯文本展示。不会执行记忆中的指令、打开其中的外部链接或修改记忆文件。

## 默认扫描范围

| Agent       | 默认文件 / 目录                                                            |
| ----------- | -------------------------------------------------------------------------- |
| Codex       | `~/.codex/memories/` 中的 Markdown，以及 `~/.codex/AGENTS.md`              |
| Claude Code | `~/.claude/projects/*/memory/`，以及 `~/.claude/CLAUDE.md`                 |
| Gemini CLI  | `~/.gemini/GEMINI.md`；实际存在的 `~/.gemini/tmp/*/memory/` 下的 Markdown  |
| Cursor      | `~/.cursor/rules/` 中的 Markdown / MDC                                     |
| OpenCode    | `~/.config/opencode/AGENTS.md`；不存在时列出兼容来源 `~/.claude/CLAUDE.md` |

「选择项目」读取该项目根目录的相应指令入口，如 `AGENTS.md`、`CLAUDE.md`、`GEMINI.md`、`.cursor/rules/`。不会递归扫描整个项目。

「添加记忆目录」只对当前 Agent 添加一个手动来源。项目和手动目录在当前应用进程内保留，重启后重新选择。任意自定义配置路径、远端记忆、MCP 数据库、聊天全文以及 Gemini `.patch` 待审核候选不在默认适配范围，可选择实际 Markdown 存放目录浏览。

文件存在不代表 Agent 当前启用、载入了它，也不表示规则已经生效。自选文档、自动记忆和持久指令在界面中分别标记。

## 读取边界

单文件最多 256 KB，一次最多 100 个文件 / 4 MB / 8000 个内容节点 / 4000 个目录项，默认目录深度最多 4 层。超限、无法读取和未发现的来源在「读取范围与状态」中显示，不以演示内容补齐。

跳过符号链接、聊天记录、缓存、技能目录及二进制文件。已知格式的密钥和凭据在展示前脱敏，保留原始行号，源文件不变。浏览器演示不会读取本机文件。

## 验证

```sh
node --import tsx --test tests/memory.test.ts
npm run build
node scripts/verify-memory-workbench.mjs
```

界面验证启动真实 Electron / preload / IPC，在隔离临时主目录中生成测试文档并禁用网络。覆盖跨文件阅读、常驻目录、文件聚焦与原文、来源定位、主题展开、原文中的场景和示例、关系图与引用往返、五个标签、目录选择与取消、键盘切换、分页、刷新后的布局、缺失来源、输入校验与源文件保持不变。

可设置 `NETWORK_LENS_MEMORY_SHOTS_DIR` 保存该验证的桌面和窄屏截图；截图仅包含测试数据。

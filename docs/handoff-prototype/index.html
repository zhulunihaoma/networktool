2. 确认接续目标

先选择一项任务，或导入 OpenCode 原生导出 JSON。导入记录只在本次应用内存中保留。

读取后列表来源 ID 与目录会显示在卡片上；不会自动切换工作区，目标工具打开同一目录前不会开始下一步。

# 文件策略交互原型 v2

用 Chrome、Edge 或 Safari 打开本目录的 `index.html` 即可使用，无需构建或联网。

完整产品、技术与交互方案：[文件策略-技术与交互方案](../../plans/文件策略-技术与交互方案.md)。

## 可以体验什么

- Windows/macOS × 开发/办公四个独立演示环境，切换会保留各自的策略与记录。
- 五个页面：保护工作台、文件发现、任务与验证、授权与记录、覆盖与健康。
- 新增发现闭环：扫描固定元数据候选 → 确认或暂缓 → 推荐模板 → 试运行发布 → 文件状态自动更新；回滚后重新计算。
- 新增任务看板与安全替代：密钥被拒绝后可以改用不含生产值的样例配置继续，原始凭据仍禁止读取。
- 新增条件变化演示：文件更新、目的地改变使旧授权和副本预览失效；历史询问也不能生成旧许可。
- 新增失败恢复：规则允许但执行失败时显示任务未完成；重试成功后才完成。执行失败仍消费单次许可。
- 原始请求、授权、重试与替代材料之间可从记录详情相互查看。
- 新建策略：选文件 → 独立设置读/改/删/发送模型 → 试运行 → 确认发布。
- 新策略发布后，其四种操作自动进入任务与验证列表，可验证实际使用的新规则。
- 下发失败保留草稿和上一版本；取消“演示一次下发失败”后可重试；工作台可以回滚。
- 需确认的操作可申请 1 次 / 15 分钟授权，填原因后回场景重试；第二次操作重新询问。
- 授权支持撤销、模拟到期；策略修订后旧授权失效。
- 办公薪资场景可预览脱敏副本、确认并模拟提交；原件仍遵守原外发规则。
- 系统增强初始未就绪：模拟接入后可以验证覆盖变化；也可模拟权限失效和恢复。
- 记录支持提交搜索、筛选、查看证据抽屉；“清空”只清输入，点击搜索才更新结果。
- “导出演示报告”生成 JSON 下载，包含明确的模拟来源，隐藏填写的授权原因。
- 浏览器本地存储只保留演示数据。页尾“重置演示数据”可恢复全部模板。

## 推荐演示顺序

0. 文件发现 → 扫描示例 → 确认一项候选 → 试运行发布 → 查看状态从待确认变为已配置。

1. 默认 macOS 开发环境 → 任务与验证：源码读取允许、密钥读取禁止。
2. 未知终端读取密钥：初始未覆盖 → 覆盖与健康 → 系统增强模拟接入 → 重试后禁止。
3. AI 修改发布配置：需确认 → 仅授权一次 → 重试允许 → 再试重新确认。
4. 切换日常办公 → 薪资外发 → 预览脱敏副本 → 确认提交副本。
5. 新建策略 → 试运行 → 发布时模拟一次失败 → 取消失败模拟并重试 → 任务与验证查看新规则 → 回滚。
6. 授权与记录 → 查看操作依据 → 下载报告。

## 验证结果与限制

执行命令：

```sh
node docs/prototype/file-policy/verify.mjs
```

2026-11-11：20 组行为检查通过。脚本提取原型实际 JavaScript，以 Node VM 和最小 DOM 替身运行，检查真实的原型决策、授权消费、失效、发布失败重试、回滚、新规则进入场景、环境隔离与导出创建逻辑。

这验证了逻辑，不验证浏览器渲染。尚未完成：真实浏览器点击、窄屏视觉、原生对话框键盘焦点与文件下载落盘检查。前一轮无头 Chrome 在沙箱内启动失败；沙箱外启动请求因自动审批服务额度上限未获执行。本轮没有重试绕过审批，也没有截图成果。

布局按 1920/1440/1366/1280 自适应设计；小于 1100 内容单列；小于 768 工具条换行、表格内部横向滚动。以上为实现规则，尚未完成浏览器视觉验收。

所有“已阻止”“已允许”“探针通过”均为原型模拟。未实现 OS 驱动、Endpoint Security、真实 Hook 接入、文件内容解析脱敏或模型提交通道。源代码不访问真实文件，不写系统配置。

设计采用 security-console-design 科技绿离线预览 token；没有外部图片和正式品牌图标。独立模块沿用安全中心语义，未设计新的全局导航。原型简化了企业角色、审批流与海量列表分页；这些生产要求已在方案中定义。

新版采用独立的 v2 浏览器存储空间，避免复用旧版不含版本快照的授权。若页面仍显示旧内容，请刷新本地 HTML。

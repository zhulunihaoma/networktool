# 安全中心原型说明

单文件 HTML 原型，直接用浏览器打开 `index.html` 即可。不依赖项目构建，不读写任何本地配置，全部数据为演示数据。

## 页面

| 页签 | 对应功能 | 重点表达 |
| --- | --- | --- |
| 概览 | 安全评分、今日态势、保护范围 | 五类证据分开计数，不合并成单一风险数 |
| 事件时间线 | P0 安全事件时间线 | 项目 / 工具 / 尝试的操作 / 命中规则 / 是否执行 |
| 操作保护 | P0 项目级操作保护 | 规则表达式、优先级、启用状态与未覆盖范围 |
| 安装前检查 | P1 Skill / MCP 安装前检查 | 来源、启动命令、外部地址、变更行高亮 |
| 配置体检 | P0 Agent 权限配置体检 | 当前值、风险级别、建议的最小权限 |

## 交互

- 顶部页签切换，左侧同名子菜单同步高亮（原型中仅视觉）。
- 时间线点击展开判定依据，再点“查看完整依据”打开右侧抽屉；`Esc` 关闭。
- 时间线支持按证据来源筛选；规则开关可切换并给出提示。
- 所有导出、复制、保存动作只弹提示，不产生真实文件。

## 与真实实现的差距

- 操作保护只演示 WisCode `git push` 一种操作，未接入真实执行前钩子。
- 时间线事件为静态示例，没有持久化、分页与哈希链。
- 安装前检查的 diff 为示意内容，未读取真实 Skill 文件。
- 配置体检未解析企业策略与项目级继承，"运行时实际生效值"明确标注为未验证。

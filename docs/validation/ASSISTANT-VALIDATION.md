## 原生界面验证

`scripts/verify-assistant-ui.mjs` 在临时用户数据目录运行真实 Electron 窗口，文件仅来自临时测试项目。原生目录/保存对话框返回值在该验证实例中替换为测试路径，生产代码仍使用原生对话框。工具发现读取真实的已知元数据。

已验证：默认不启动网页平台探测；本机工具详情；组件与失败功能选择；会话冻结版本与取消；文件范围、独立策略保存与修改请求自检；确认提醒不解除规则；操作筛选；报告预览与实际文件内容一致；旧预览拒绝；任意路径、未知操作和过期 revision 被 IPC 拒绝；1024 × 720 无横向溢出；无页面异常。

组件诊断在主动网络探测前取消，因此此次界面验收不证明目标平台、真实模型功能或流式连接可用。扫描和策略测试只证明助手入口，没有第三方工具文件访问或系统阻断实测。可复查 `ASSISTANT-UI-result.json` 与 `../screenshots/installed-tools.png`、`file-policies.png`、`file-audit.png`。

## 测试与构建

最终完整测试 45 项通过，0 失败、0 跳过；TypeScript、Vite、Electron 主进程和 preload 构建通过；新增模块格式检查通过。原生界面最终记录为 `ASSISTANT-UI-result.json`，`contextFrozen`、`exportPreviewMatchesSavedFile`、`staleAuditPreviewRejected` 为 true，页面错误数组为空。

使用项目要求范围内的 Node.js 24.19.0。新增测试覆盖安装稳定排序、多安装/版本更新、名称与镜像区分、未知组件拒绝、适配发布门槛、元数据预算/取消/链接、独立策略、并发 revision、对象替换失效、自检去重、确认不改策略、审计分页、默认脱敏与别名、落盘失败恢复、手动候选范围与 macOS 路径别名。

复验命令：

```sh
node --import tsx --test tests/*.test.ts
npm run build
node scripts/verify-assistant-ui.mjs
```

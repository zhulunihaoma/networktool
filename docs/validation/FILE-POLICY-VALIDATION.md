# 文件策略正式实现与验证

日期：2026-11-11。入口：安全中心 → 文件策略；原“文件策略与审计”入口复用同一组件。更新构建后需重启应用，保证稳定副本中的守卫脚本更新。

## 已接入正式程序

- 五个正式分区：保护工作台、文件发现与策略、本地处理任务、授权与记录、覆盖与健康。
- 真实元数据扫描、手动添加范围内文件、候选确认/暂缓/恢复；不默认读取正文。
- 四种独立动作（读、改、删、发送模型），开发凭据与办公资料模板。
- 草稿试运行凭证绑定文件身份、策略版本和五分钟期限；修改草稿后重新试运行；发布前确认。
- 发布、回滚、版本冲突检测、旧授权失效、钩子快照下发与回读一致性检查；失败保留输入、显示具体状态并提供重试。
- 打包守卫加载文件规则快照；对可解析的文件读写/删除目标应用限制。旧命令规则拒绝仍然优先；文件规则不会被项目例外覆盖。
- 同一文件在多个范围内按 deny > ask > allow 合并；试运行、自检、本地读取和钩子限制不因范围切换放宽。
- 本地受控文本预览与脱敏副本：真实读取前核验身份/版本；单次权限绑定本地任务，15 分钟一次，消费后不可重放；过期、撤销、重启、文件或策略变化失效。
- 正文通过文件句柄读取，限制 256 KiB、UTF-8、常规单链接文件；读取中变化、特殊文件、二进制或大文件失败会产生任务未完成回执。
- 脱敏处理密钥赋值、私钥块、邮箱、手机号、长数字候选；姓名、商业秘密等可能保留，要求用户预览确认。保存时重新核验源版本及副本摘要，且只允许创建新文件，不覆盖原件或其他现有文件。
- 任务、授权、完成/失败与发布事件通过任务编号关联；导出 schema v2 保留结果与字节回执，隐藏路径、正文、授权原因及其他自由文本。

## 清楚保留的能力边界

- 当前本地处理是本应用的明确入口，不约束所有本机应用。
- 文件规则快照写入和回读一致，不等于 AI 工具已经加载执行前钩子；工具实际状态和钩子事件在安全中心“操作规则 / 安全事件”核验。
- 钩子“需确认”先阻断。本地任务的单次许可不能用于 AI 工具；原操作规则可能更严格，允许项不会覆盖已有拒绝。
- 只覆盖钩子载荷明确暴露或可解析出的路径。任意脚本、远程、WSL、容器和其他执行环境未验证。
- 没有实现或安装 Windows Minifilter、macOS Endpoint Security；两平台原生系统防护不能标记已完成。
- 没有模型提交网关或模型接收回执；“生成/保存本地副本”不代表向模型提交。“发送模型”规则当前可保存和自检，界面明确标记未接入执行通道。
- Word、Excel、PDF 解析尚未接入；本地处理只支持 UTF-8 文本。禁止读取的原件不能通过脱敏入口绕过。

## 2026-11-11 文件变更与快照恢复复验

- 已启用规则的文件被修改、替换、删除、扫描跳过或被符号链接替换后，保留原路径规则并标记“版本待确认”；经过文件守卫、能够识别该路径的请求继续被拒绝，本地任务不能读取。新文件版本经过用户确认后，生成新策略修订，旧单次授权和旧试运行不可复用。
- 已有文件防护的安装会建立所需标记；策略快照缺失时，守卫无法判定受影响路径，因此暂时拒绝经过该守卫的操作。页面显示错误及重新下发入口。未初始化文件防护的旧版安装不因缺少标记改变行为。
- macOS 缺失文件和最终符号链接的匹配基于真实父目录，覆盖 `/var` 与 `/private/var` 的路径别名。相关测试使用本机临时文件；Windows 尚未进行真机验收。
- 查看未配置候选而没有修改时，切换分区不再提示丢弃草稿；用户修改后仍保留离开确认。授权创建后按钮明确指向执行该任务；禁止读取时引导到文件列表添加安全样例。
- 应用内单次授权仍只适用于本地文本任务。系统级、未加载钩子、未暴露路径的脚本或其他应用仍未纳入守卫覆盖；同账号恶意进程删除整个本地防护目录也不属于本层可抵抗的威胁模型。

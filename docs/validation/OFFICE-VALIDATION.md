# 0.2 普通办公用户版验收

2026-10-03，macOS Apple Silicon 开发及桌面验收。

## 产品改动

- 默认首页改为 AI 工具体检，打开即自动检查 14 个预置平台，不要求输入域名、PID、端口或代理参数。
- 国内：豆包、DeepSeek、Kimi、腾讯元宝、千问、WPS AI、飞书 AI。
- 海外：ChatGPT、Claude、Gemini、Microsoft Copilot、Perplexity、Notion AI、Cursor。
- 状态区分入口可连接、入口要求登录、访问受限、服务响应异常、网络失败、检测未完成；系统路径与补充路径分别列出，不用其他路径的成功掩盖系统路径失败。
- 支持国内 / 海外 / 需要关注 / 正在运行筛选，运行客户端采用进程名称边界匹配。
- 普通用户直接查看建议、单平台复测和复制给 IT；技术信息默认折叠，反馈中标明系统路径与补充路径，并移除进程路径、代理端点及原始自由文本。
- 0.2.1 源码增量：卡片显示系统、直连和代理各自的 HTTP / TLS / 连接结论；单平台按钮可在列表中发起，并显示探测阶段进度。VPN 地区、分流与本机代理监听端口的处理步骤见 [VPN 网络访问检查和处理方案](../plans/VPN-网络访问检查和处理方案.md)。
- 原有诊断、应用连接观察、联网对比和导出功能收在“高级排查”，本地历史未删除。

## 测试和桌面证据

- 29 项测试通过，0 失败、0 跳过。新增测试覆盖平台目录、HTTP 状态、不能推断账号失效或全球故障、代理 / 证书 / 域名解析建议、进程归因边界、反馈隐私、最多四个并发、停止后的迟到结果隔离、复测频率与进程读取失败。
- TypeScript / Vite / 主进程构建通过，Prettier 检查通过，`git diff --check` 无报错。仓库仍无初始提交，格式检查覆盖新增源码。
- 原生桌面开发版自动检查完成，实际出现入口可连接、网络失败和路径不一致结果；识别到飞书与 ChatGPT 的运行客户端。
- 点击异常平台后看到下一步建议；“复制结果给 IT”显示已复制，原始自由文本未进入反馈内容。
- 0.2 打包程序从 `app.asar` 启动，自动扫描状态从检查中到完成；国内筛选与正在运行筛选操作正常。其中一轮结果为 12 个入口可连接、2 个尚无确定结果；最终截图一轮为 11 个入口可连接、3 个尚无确定结果。该截图和检查属于 0.2 版本，结果随当前网络变化，不是各平台长期服务状态。
- 0.2.1 本轮已执行 `npm run build`，TypeScript 检查与生产构建通过；macOS ARM64 应用/ZIP 和 Windows x64 安装包均已重新生成。此次未运行自动化测试或新一轮实时网络/UI验收；Windows 包仍需 Windows 实机验证。
- macOS ARM64 应用和 ZIP、Windows x64 NSIS 安装包均生成成功；最终首页截图已保存。

## 范围与限制

- 当前检测公开网页入口，不验证真实 AI 对话、上传、登录、企业租户或客户端后端的全部依赖。WPS、飞书、Notion、Cursor 的官网入口尤其不能替代其 AI 服务端检测。
- 不读取浏览器历史、账号 Cookie、聊天内容或文档，不发起真实生成任务。
- 未运行的桌面工具不标记为“未安装”；浏览器中正在使用的平台不从 IP 或浏览器进程名称猜测。
- 平台列表不代表所有主流产品的完整集合；服务域名变化后需要更新目录及官方来源。
- Windows 安装包构建与 Windows 实机验收分开：Windows 11 运行及采集尚未实测。安装包未配置发布签名，macOS 未公证。
- 运行时依赖上一轮审计为 0 告警；构建依赖仍有尚无上游修复的 `http-cache-semantics` 关联告警，详见 0.1 验收记录。

平台及其官方入口来源可查看 `src/shared/platforms.ts`；最终截图见 `docs/screenshots/office-home.png`，安装包校验见 `checksums-0.2.txt`。

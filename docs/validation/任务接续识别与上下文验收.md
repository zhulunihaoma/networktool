## 改造行为

- 桌面实际调用切换到持久化全量元数据索引，按来源、项目、会话类别分页并搜索全部索引。保留空项目、归档、子会话、自动化、草稿及独立残留记录。
- ZCode 不再用 sess_ 前缀排除 session_；OpenCode 直接合并原生新旧存储；WisCode 联合原生宿主和引擎记录；Cursor 按 UNIQUE key 正确读取正文及 NULL 占位记录。
- Codex 同时处理索引中未更新的压缩路径、串联 Zstandard 帧、没有状态库登记的压缩日志，以及文件名为父 ID_分支 ID、首条元数据仍为父 ID 的历史。
- 完整上下文和附件流式落盘，以 SHA-256 和输入偏移验证；支持重启缓存和取消后续读。正文与附件状态分开显示；全量核验提供进度、取消和具体缺口列表。
- 移除桌面新读取与导出链路的 8 MB、5000 消息、120000 字符总量限制；分页预览保留单次资源限制。旧兼容适配器的限制不再用于桌面全量链路。
- 原始上下文和附件导出为本机目录，复制提示明确引用完整包；预览不能冒充全文。读取更大的文件不代表改变目标模型本身的上下文窗口。
- 原始历史作为引用数据处理，不运行历史命令，不调用模型，也不为读取来源执行数据库迁移。
